First 30 Days

Clearing the unknown.

Week 1-2: Test and measure format
Ship 2-3 content formats for each product. Threads, videos, carousels. See which gets engagement and link clicks. Keep the winner.
Week 3-4: Scale winning format
Run 5-7 variations of the winning format. Test copy angles, problem angles, audience segments. Identify which resonates and converts to signups.
Outcome by day 30
Know which platform works. Know which format works. Know which angle converts. Have 200-400 engaged followers. Have 15-30 signups from content. Have clear direction for month 2.
Success looks like
Data points that aren't guesses. A clear answer to "which channel, which format, which angle works?" And a system in place to keep testing without me. That's month 1 done.
